To replace or add one, keep the same file name (PNG), crop to the relevant panel, keep it under about 500 KB, and hide or blur:
account ID, agent / environment / vault / skill IDs, session IDs, endpoint IDs, API keys, bucket name,
function address, user names, email addresses and anything confidential.
